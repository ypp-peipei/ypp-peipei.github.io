# Yansong Pei — academic homepage

Public website: https://ypp-peipei.github.io/

The repository root contains the static website served by GitHub Pages. Pages deployment uses the `main` branch and root folder.

## Editing

Download and unpack [website-source.zip](website-source.zip) for the complete editable source, structured publication and profile data, generator, responsive styles, and optional GitHub Actions workflow. Edit `data/profile.json` or `data/publications.json`, run `python3 scripts/build.py --production` and `python3 scripts/check.py`, then upload the generated `dist/` files here. Update the source archive alongside substantive edits.

The website includes research projects, publications and BibTeX, a printable CV, public research resources, and a Chinese introduction. No analytics scripts are included. Only intended public website content is included in this repository; original private research files are not bundled.

Content assembled in October 2026 from the author's academic CV, research materials, institutional information and selected publisher records. Accepted and under-review work is labeled separately. Indexing in search engines is not guaranteed.
